# 도메인 모델

구현된 애그리거트 루트별로 책임과 하위 모델의 의미를 간략히 기록한다. 다른 애그리거트의 모델은 하위 모델과 구분한다. 필드·메서드 목록과 공통 설계 기준은 반복하지 않는다.

## 작성 형식

실제 모델이 생기면 아래 형식으로 항목을 추가하고, 해당하지 않는 항목은 생략한다.

```md
## [애그리거트 루트]

- 역할: [담당하는 업무]
- 하위 모델:
  - [모델]: [역할과 루트에 속하는 이유]
- 다른 애그리거트와의 관계: [참조 대상과 이유]
- 핵심 규칙: [항상 지켜야 하는 업무 규칙이 있을 때만]
```
