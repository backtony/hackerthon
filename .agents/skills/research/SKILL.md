조사는 새 컨텍스트의 **백그라운드 에이전트**에 맡기고, 그동안 현재 작업을 이어간다.

조사 에이전트의 역할:

1. 공식 문서, 원본 코드, 명세, 제공자의 API 등 **1차 출처**로 질문을 조사한다. 다른 사람이 요약한 글에 의존하지 않고 각 주장에 해당하는 원출처를 확인한다.
2. 조사 결과를 주장별 출처와 함께 Markdown 파일 하나에 기록한다.
3. 저장소의 기존 조사 문서 위치와 형식을 따른다. 관례가 없으면 적절한 위치에 저장하고 경로를 알린다.
